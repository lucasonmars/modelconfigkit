# ModelConfigKit

**Download once. Configure any model.**

A downloadable AI model **configuration knowledge base**. Embed it in your AI app so users only fill **provider + model + API Key**. Endpoints, param names, defaults, and multimodal formats come from the kit. Overrides are allowed.

> Not a gateway. Not a proxy. A local registry your software queries to know how to call each model.

## What it does

| User fills | Kit supplies |
|------------|--------------|
| Provider | Matching adapters + base URL |
| Model | Capability facts + limits + directional tasks |
| API Key | Kept local — never sent to a third party |

Annoying params (`max_tokens` vs `max_completion_tokens`, `top_k` strip, image format…) get sensible defaults and mapping. Your app can still let power users override.

## Install

```bash
npm install modelconfigkit
```

## Usage

```ts
import { loadBundledRegistry, createClient, queryModels, getStats } from "modelconfigkit";

loadBundledRegistry();
console.log(getStats().model_count);

const { config, chatPayload } = await createClient({
  provider: "openai",
  model: "gpt-4o",
  apiKey: process.env.OPENAI_API_KEY,
  overrides: { temperature: 0.2, max_tokens: 512 }, // optional
});

const req = chatPayload({
  messages: [{ role: "user", content: "hello" }],
});
// fetch(req.url, { method: "POST", headers: req.headers, body: JSON.stringify(req.body) })
```

Filter models by capability:

```ts
queryModels({ task: "text-to-image" });
queryModels({ input: "image", output: "text" });
```

CLI:

```bash
npx modelconfigkit stats
npx modelconfigkit resolve --provider deepseek --model deepseek-chat
npx modelconfigkit query --task text-to-image
```
